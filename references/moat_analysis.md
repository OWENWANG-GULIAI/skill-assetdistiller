# 护城河分析

## 七个维度

- 情境稀缺：少见行业、阶段、规模或约束；
- 关键判断：能诊断、排序、取舍，不只执行；
- 跨界组合：两到三类能力在同一交付中互相增强；
- 方法沉淀：形成 SOP、模板、工具、课程或标准；
- 结果证据：有采用、复购、转介绍或前后变化；
- 信任迁移：经授权的客户、身份与案例降低购买风险；
- 平台独立性：离开原单位后仍能独立交付。

每项用 1-5 级表示强弱，并写证据与限制。没有事实支撑时不得因为“看起来高级”而给高分。

## 平台剥离测试

分别列出：

- 可带走：判断、方法、SOP、模板、个人完成的交付、经授权案例；
- 不可直接带走：原公司品牌、团队能力、内部数据、预算、客户关系、渠道和审批权限。

真正的护城河要同时回答“为什么难替代”和“在什么条件下会失效”。
